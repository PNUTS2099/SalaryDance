# SalaryDance / 薪跳

薪跳 for 所有苦逼打工人。

当前版本优先提供可验收的单文件原型：

- `index.html`：包含页面结构、样式、计算逻辑、币种切换、本地存储和钱包收钱动画。
- `薪跳demo.html`：与 `index.html` 同步的中文命名演示文件。

## 当前功能

- 实时工资滚动
- 税前 / 税后收入切换
- 人民币进钱包动画
- 币种切换
- 提前下班与实际时薪计算
- 近 7 天工时和时薪波动
- 拉屎 / 摸鱼计时器
- 今天 / 本周 / 本月摸鱼收入统计

## 小程序迁移建议

为了避免后续重复开发，当前 HTML 已按小程序可拆分的方式组织：

- 配置数据：对应小程序本地缓存，例如 `monthlySalary`、`currency`、`workDaysPerMonth`、`startTime`、`endTime`。
- 计算逻辑：可迁移为独立工具函数，例如薪资换算、税后估算、工作状态判断、今日已赚计算。
- 页面状态：可拆分为首次设置页、实时赚钱页、币种选择面板。
- 动画逻辑：可保留“按收入增量生成钱币”的规则，小程序侧替换为 `view` 动画或 canvas 动画。
- 提前下班：当前用本地历史记录保存每日实际工时、实际时薪和结束方式，小程序侧可迁移到本地缓存或云开发数据库。
- 摸鱼计时：当前用本地记录保存拉屎 / 摸鱼时长和按秒薪折算的收入，支持今天、本周、本月汇总。

MVP 暂不接入登录、云存储、汇率换算和真实钱包能力。
