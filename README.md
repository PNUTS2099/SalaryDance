# SalaryDance / 薪跳

给打工人看的实时工资钱包。

这个仓库现在包含两套内容：

- `index.html`：原始单文件 Web 原型，保留作为参考和演示。
- `miniprogram/`：微信小程序迁移版，可导入微信开发者工具预览、真机调试和上传。

## 小程序已迁移功能

- 首次工资、币种、工作日、上下班时间设置
- 税前 / 税后收入切换
- 月度个税估算
- 实时今日已赚金额
- 日薪、时薪、分钟薪、秒薪指标
- 提前下班和恢复计算
- 近 7 天实际工时 / 实际时薪记录
- 拉屎 / 摸鱼收入计时器
- 今天 / 本周 / 本月摸鱼收入统计
- 本地缓存保存配置和记录
- 轻量钱包入账动画

## 本地验证

项目核心计算逻辑可以用 Node 直接验证：

```powershell
node --test tests\core.test.js
```

## 导入微信开发者工具

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录：`SalaryDance`。
4. 如果只是预览，可先使用测试号；如果要上传发布，请把 `project.config.json` 里的 `appid` 改成你的小程序 AppID。
5. 点击“编译”，检查页面是否正常显示。
6. 使用“预览”生成二维码，在手机微信里真机测试。

完整发布步骤见 `docs/wechat-miniprogram-release.md`。
