# 薪跳秒表

薪跳秒表是一款给打工人使用的实时工资小工具。

输入月薪、工作天数和上下班时间后，它会帮你估算今天已经赚了多少钱，也能把日薪、时薪、分钟薪、秒薪换算出来。上班时看着数字一点点跳动，摸鱼也更有仪式感。

## 主要功能

- 实时显示今日已赚工资
- 估算日薪、时薪、分钟薪和秒薪
- 支持税前 / 税后收入切换
- 支持月度个税估算
- 支持提前下班，并计算当天实际时薪
- 记录近 7 天实际工时和实际时薪
- 支持拉屎 / 摸鱼计时
- 统计今天、本周、本月的摸鱼收入
- 支持多币种显示
- 本地保存工资设置和历史记录

## 适合谁

- 想知道自己今天已经赚了多少钱的人
- 想把月薪换算成时薪、分钟薪、秒薪的人
- 想记录实际工时和提前下班收益的人
- 想给摸鱼时间算一笔账的人

## 隐私说明

当前版本不需要登录，也不会把工资、工时或摸鱼记录上传到服务器。

你的数据保存在微信本地缓存中，删除小程序或清理缓存后，本地记录可能会被清除。

## 当前版本说明

薪跳秒表是一个轻量工具，不提供真实钱包、支付、提现或理财功能。页面中显示的金额仅用于个人估算和娱乐参考。
